Saran buffer per grup dan SKU

Buffer = z × sebaran error × forecast × √(lead time ÷ 30) × faktor strategi. z: 90% = 1,28 · 95% = 1,64 · 98% = 2,05. Sebaran error dihitung per famili dari error forecast 6 closing terakhir (×1,4 di level SKU); bila histori kurang dari 2 bulan dipakai 25%. Otomatis memilih strategi per SKU lewat backtest 6 closing terakhir (skor: kurang 2× lebih berat dari lebih); SKU dengan histori sedikit ikut kelas ABC-XYZ-nya. Kuantil (P90) memakai rentang forecast SKU itu (Chronos, regressor kuantil, atau error historis). Klik angka Buffer final untuk mengubah (alasan wajib), pilih Strategi per famili atau SKU, klik Status untuk rincian hitungan. SKU diskontinu/diganti tidak dihitung.

Material master

Gabungan material master (bila diunggah) dan SKU di Forecast HQ dan closing. Status (satu kolom untuk semua): Aktif = dijual dan dihitung; Perlu cek = kena aturan, putuskan sendiri; Diskontinu = berhenti tanpa pengganti; Diganti = berhenti dan penjualannya pindah ke Nomat baru. Diberi otomatis dari status master dan Aturan status otomatis di bawah; klik label status untuk mengubahnya. Diskontinu dan Diganti tidak dihitung di total, akurasi, ML, buffer dan PP. Brand dan Kategori master dipakai untuk kelompok di lembar Forecast. Kolom Perubahan menandai Nomat yang berganti untuk kode artikel yang sama, nama yang berbeda, dan SKU yang belum ada di master.
Jenis SKU mengklasifikasi tiap Nomat (Reguler, SKU baru, Musiman, Musiman + histori, Diganti); kolom Detail jenis hanya menampilkan isian untuk jenis itu. Histori dari Nomat: untuk SKU baru (NPD) yang biasanya hanya beda kemasan. SKU baru memakai order in Nomat lama × persen untuk bulan sebelum order in-nya sendiri, jadi semua model punya histori; Nomat lama tetap aktif. Bila Nomat lama berhenti, isi Nomat pengganti di baris Nomat lama (histori pindah penuh). Musim aktif: bulan SKU dijual (mis. Feb-Apr, 11-1, 2027-02..2027-04); di luar musim forecast, buffer dan PP 0 dan status nonaktif. Kolom bebas: isi sendiri per Nomat (mis. MT / GT, slow moving) untuk saringan dan kelompok di lembar Forecast; tidak dipakai model.

Aturan status otomatis

Data closing tidak selalu rapi: SKU lama, salah grup atau salah input bisa merusak akurasi dan ML. Aturan di bawah memberi status otomatis. Matikan aturan atau ubah angkanya bila tidak cocok, lalu ubah status per SKU di tabel bila perlu. Semua pengaturan ikut tersimpan di file Histori_Serang.

Master mesin

Disimpan di browser ini dan di file Histori_Serang (bukan di kode). Nama asli hanya tersimpan terenkripsi.

Output karton/hari = kapasitas kg/hari ÷ berat bersih kg/karton × variasi output %. Kapasitas t/bulan dihitung dari kapasitas kg/hari × variasi output × 26 hari kerja bila kg/hari diisi. Di Rencana produksi berat bersih per SKU dari closing yang dipakai; berat di sini hanya acuan. Ketik langsung, atau tempel blok dari Excel (Ctrl+V) di sel pertama. Kode mesin dipakai di semua jadwal dan file; nama asli hanya tampil setelah kunci dibuka.

Daftar mesin

Kelompok SKU → area mesin

Kelompok SKU memetakan SKU ke area mesin lewat kata di nama SKU (mis. Soft Pack) atau nama famili; bila beberapa cocok, yang paling panjang menang. Kalender: libur nasional dan cuti bersama 2026–2027 sudah bawaan (SKB 3 Menteri), Sabtu masuk, Minggu libur; ubah per tanggal di jadwal.

Unduh histori Serang

File gabungan berisi lembar bulanan (satu baris per SKU per bulan closing), mingguan (W1–W5), forecast_hq, kelas_sku dan log. Bulan yang diunggah ulang menggantikan bulan yang sama; penggantian dicatat di lembar log. Histori ringkas (.ppic.gz) berisi data yang sama dengan Excel, dikompresi (biasanya 10–20× lebih kecil); unggah atau tarik file itu untuk melanjutkan.

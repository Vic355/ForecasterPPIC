Saran buffer per famili dan SKU

Buffer = z × sebaran error × forecast × √(lead time ÷ 30) × faktor strategi. z: 90% = 1,28 · 95% = 1,64 · 98% = 2,05. Sebaran error dihitung per famili dari error forecast 6 closing terakhir (×1,4 di level SKU); bila histori kurang dari 2 bulan dipakai 25%. Klik angka Buffer final untuk mengubah (alasan wajib), pilih Strategi per famili atau SKU, klik Status untuk rincian hitungan. SKU diskontinu/diganti tidak dihitung.

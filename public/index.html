Seperti Excel: klik dua kali atau langsung ketik di sel Stok, Order in, Forecast HQ untuk mengoreksi. Enter/Tab untuk lanjut, Esc batal, Delete mengosongkan, Ctrl+Z membatalkan. Selisih = Forecast HQ − Order in. Merah: HQ di atas order in.Forecast ML (prototipe): Holt pada order in + Forecast HQ dikoreksi biasnya per SKU. Arahkan kursor ke angka ML untuk rinciannya.Sinyal HQ dibanding ML: ▼ HQ ≥20% di atas, ▼ 5–20% di atas, ≈ beda <5%, ▲ 5–20% di bawah, ▲ ≥20% di bawah.Tanpa HQ ada order in / ML tapi Forecast HQ kosong.

Saran buffer per famili dan SKU

Buffer = z × sebaran error × forecast × √(lead time ÷ 30) × faktor strategi. z: 90% = 1,28 · 95% = 1,64 · 98% = 2,05. Sebaran error dihitung per famili dari error forecast 6 closing terakhir (×1,4 di level SKU); bila histori kurang dari 2 bulan dipakai 25%. Klik angka Buffer final untuk mengubah (alasan wajib), pilih Strategi per famili atau SKU, klik Status untuk rincian hitungan. SKU diskontinu/diganti tidak dihitung.
